# Sneltoetsen

Harmonie ondersteunt diverse sneltoetsen om sneller te navigeren en te werken. Druk op **?** om dit overzicht in de app te tonen.

## Navigatie

Navigatiesneltoetsen werken met **G** (Go) gevolgd door een tweede toets. Druk eerst op **G**, wacht even, en druk dan de tweede toets.

| Sneltoets | Actie |
|-----------|-------|
| **G H** | Ga naar Dashboard (Home) |
| **G M** | Ga naar Mijn Muziek |
| **G L** | Ga naar Lijsten |
| **G T** | Ga naar Titels |
| **G R** | Ga naar Repetities |
| **G C** | Ga naar Concerten |
| **G S** | Ga naar Instellingen |
| **G P** | Ga naar Profiel |
| **G U** | Ga naar Uploaden |

### Alternatieve navigatie (Alt-toetsen)

Dezelfde navigatie is ook beschikbaar met de Alt-toets (of Option op Mac):

| Windows | Mac | Actie |
|---------|-----|-------|
| **Alt+H** | **Option+H** | Ga naar Dashboard |
| **Alt+M** | **Option+M** | Ga naar Mijn Muziek |
| **Alt+L** | **Option+L** | Ga naar Lijsten |
| **Alt+T** | **Option+T** | Ga naar Titels |
| **Alt+R** | **Option+R** | Ga naar Repetities |
| **Alt+S** | **Option+S** | Ga naar Instellingen |
| **Alt+P** | **Option+P** | Ga naar Profiel |
| **Alt+U** | **Option+U** | Ga naar Uploaden |

## Werking van sneltoetsen

### Sequentie-sneltoetsen (G + toets)

De **G**-sneltoetsen werken als een sequentie:
1. Druk op **G** en laat los
2. Je ziet "Wacht op tweede toets..." verschijnen
3. Druk binnen 1 seconde de tweede toets (bijv. **H** voor Home)
4. Je navigeert naar de pagina

Als je geen tweede toets indrukt binnen 1 seconde, wordt de sequentie geannuleerd.

### In invoervelden

- Sneltoetsen werken **niet** wanneer je in een tekstveld aan het typen bent
- Uitzondering: **Escape** werkt altijd (verlaat het invoerveld)
- Uitzondering: **Ctrl/Cmd** combinaties werken ook in invoervelden

### Mac vs Windows

Op Mac wordt de **Cmd** (Command) toets gebruikt waar Windows **Ctrl** gebruikt. De app herkent automatisch je besturingssysteem en toont de juiste toetscombinaties.

## Sneltoetsen per pagina

Sommige pagina's hebben extra sneltoetsen die context-specifiek zijn. Deze worden getoond wanneer je **?** indrukt op die pagina.

### PDF Viewer

| Sneltoets | Actie |
|-----------|-------|
| **+** of **=** | Inzoomen |
| **-** | Uitzoomen |
| **0** | Zoom resetten |
| **Pijl links** | Vorige pagina |
| **Pijl rechts** | Volgende pagina |
| **Home** | Eerste pagina |
| **End** | Laatste pagina |

### Lijsten en tabellen

| Sneltoets | Actie |
|-----------|-------|
| **Pijl omhoog** | Vorig item selecteren |
| **Pijl omlaag** | Volgend item selecteren |
| **Enter** | Item openen |
| **Spatie** | Item selecteren/deselecteren |

## Tips

1. **Snel zoeken is je vriend**: Met **Ctrl+K** / **Cmd+K** kun je bijna alles vinden en bereiken.

2. **G voor Go**: Onthoud de G-navigatie sneltoetsen:
   - **G H**ome
   - **G M**ijn Muziek
   - **G R**epetities
   - **G C**oncerts
   - **G S**ettings

3. **Escape annuleert**: Als je per ongeluk een sneltoets activeert, druk dan **Escape** om te annuleren.

4. **Bekijk context-sneltoetsen**: Druk op **?** op elke pagina om specifieke sneltoetsen te zien.
