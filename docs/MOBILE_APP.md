# Mobiele App (PWA) Installatie

Harmonie is beschikbaar als Progressive Web App (PWA). Dit betekent dat je de website kunt installeren als een app op je telefoon of tablet. De app werkt dan ook offline en je krijgt push-notificaties.

## Voordelen van de PWA

- **Altijd bij de hand**: De app staat op je startscherm, net als een normale app
- **Offline toegang**: Bekijk bladmuziek en gegevens zonder internet
- **Push-notificaties**: Blijf op de hoogte van nieuwe muziek, repetitiewijzigingen en berichten
- **Snellere toegang**: Start direct op, zonder browser te openen
- **Volledig scherm**: Geen adresbalk of browser-interface
- **Automatische updates**: Altijd de nieuwste versie

## iOS (iPhone/iPad) - Safari

### Stap-voor-stap installatie

1. **Open Safari** op je iPhone of iPad
   - *Let op: De installatie werkt alleen via Safari, niet via Chrome of andere browsers*

2. **Ga naar de Harmonie website**
   - Typ de URL van je vereniging in de adresbalk
   - Log indien nodig in

3. **Tik op het Deel-icoon**
   - Dit is het vierkantje met een pijl omhoog, onderaan het scherm (iPhone) of bovenaan (iPad)

4. **Scroll naar beneden en tik op "Zet op beginscherm"**
   - Je ziet het Harmonie-icoon met de tekst

5. **Geef de app een naam** (optioneel)
   - Standaard heet de app "Harmonie"
   - Je kunt dit aanpassen

6. **Tik op "Voeg toe"**
   - De app verschijnt nu op je startscherm

### iOS tips

- De app werkt het beste op iOS 16 of nieuwer
- Na installatie kun je Safari sluiten; de app draait standalone
- Bij problemen: verwijder de app van je startscherm en installeer opnieuw

## Android - Chrome

### Stap-voor-stap installatie

1. **Open Chrome** op je Android telefoon of tablet

2. **Ga naar de Harmonie website**
   - Typ de URL in de adresbalk
   - Log indien nodig in

3. **Wacht op de installatie-prompt**
   - Na enkele seconden verschijnt onderaan "App toevoegen aan startscherm"
   - Of: tik op het menu (drie puntjes rechtsboven)

4. **Via de menu-optie** (als de prompt niet verschijnt):
   - Tik op de drie puntjes (menu) rechtsboven
   - Tik op "App installeren" of "Toevoegen aan startscherm"

5. **Bevestig de installatie**
   - Tik op "Installeren"
   - De app wordt toegevoegd aan je app-lade en startscherm

### Android tips

- Werkt op Chrome 73 of nieuwer
- De installatie-prompt verschijnt alleen de eerste keer
- Als je de prompt hebt genegeerd: ga via het menu (zie stap 4)
- Samsung Internet browser ondersteunt ook PWA installatie

## Beschikbare functies in PWA-modus

### Volledig werkend

| Functie | Beschikbaar |
|---------|-------------|
| Bladmuziek bekijken | Ja |
| Bladmuziek downloaden | Ja |
| PDF annotaties | Ja |
| Repetities bekijken | Ja |
| Beschikbaarheid doorgeven | Ja |
| Concertprogramma bekijken | Ja |
| Dashboard | Ja |
| Profiel bewerken | Ja |
| Zoeken | Ja |
| Berichten lezen | Ja |
| Peilingen invullen | Ja |
| Taken beheren | Ja |

### Offline werkend (na eerste keer laden)

| Functie | Offline |
|---------|---------|
| Eerder bekeken bladmuziek | Ja |
| Dashboard (gecachte data) | Ja |
| PDF's in cache | Ja |
| Repetitieschema | Gedeeltelijk* |
| Beschikbaarheid wijzigen | Wachtlijst** |

*Gecachte gegevens worden getoond, nieuwe data pas na verbinding
**Wijzigingen worden opgeslagen en gesynchroniseerd wanneer je weer online bent

## Push-notificaties instellen

### Inschakelen

1. **Open de app** (geinstalleerd als PWA)

2. **Ga naar Profiel > Meldingsvoorkeuren**

3. **Schakel "Push meldingen" in**

4. **Geef toestemming** als je browser dit vraagt
   - Tik op "Toestaan"

5. **Kies je voorkeuren**
   - Nieuwe muziek
   - Repetitie wijzigingen
   - Zitplaats updates
   - Chat berichten
   - Oefen herinneringen
   - Concert herinneringen

### Notificatie-instellingen per type

| Type | Beschrijving |
|------|--------------|
| Nieuwe muziek | Wanneer er nieuwe bladmuziek wordt toegevoegd |
| Repetitie wijzigingen | Bij wijzigingen in het repetitierooster |
| Zitplaats updates | Bij wijzigingen in de opstelling |
| Chat berichten | Nieuwe berichten in je stemgroep |
| Oefen herinneringen | Herinneringen om te oefenen |
| Concert herinneringen | Herinneringen voor aankomende concerten |

### Problemen oplossen

**Geen notificaties ontvangen?**
1. Controleer de app-instellingen op je telefoon
2. Zorg dat notificaties zijn toegestaan voor de Harmonie app
3. Controleer of "Niet storen" uit staat
4. Op iOS: ga naar Instellingen > Berichtgeving > Harmonie

## Offline mogelijkheden

### Automatische caching

De app slaat automatisch op:
- Bezochte pagina's
- Bekeken PDF's
- Je bladmuziek (Mijn Muziek)
- Basis app-bestanden (voor snelle opstart)

### Gegevens vooraf laden

Voor belangrijke repetities of concerten:
1. Open de app terwijl je wifi hebt
2. Navigeer naar de muzieklijst die je nodig hebt
3. Open elk PDF bestand dat je nodig hebt
4. De bestanden zijn nu offline beschikbaar

### Offline-indicator

- Wanneer je offline bent, zie je een indicator in de app
- Acties die niet offline werken worden uitgeschakeld
- Na herstel van verbinding synchroniseert alles automatisch

### Synchronisatie

Wanneer je weer online komt:
- Wijzigingen in beschikbaarheid worden verzonden
- Nieuwe data wordt opgehaald
- Je ziet een melding dat synchronisatie voltooid is

## Veelgestelde vragen

### Hoeveel opslagruimte gebruikt de app?

De app zelf is klein (enkele MB). PDF bestanden worden lokaal opgeslagen en kunnen oplopen afhankelijk van hoeveel muziek je bekijkt. Gemiddeld 50-200 MB.

### Kan ik de cache wissen?

Ja, via je telefooninstellingen:
- **iOS**: Instellingen > Safari > Geavanceerd > Websitegegevens
- **Android**: Instellingen > Apps > Harmonie > Opslag > Cache wissen

### Werkt de app ook op desktop?

Ja! Je kunt de PWA ook installeren op:
- Windows (via Chrome of Edge)
- macOS (via Chrome of Safari)
- Linux (via Chrome)

### Hoe verwijder ik de app?

- **iOS**: Houd het app-icoon ingedrukt > Verwijder app
- **Android**: Houd het app-icoon ingedrukt > App-info > Verwijderen

### Wordt de app automatisch bijgewerkt?

Ja. Wanneer er een nieuwe versie beschikbaar is:
1. Je krijgt een melding in de app
2. Klik op "Bijwerken" om de nieuwe versie te laden
3. De app herstart met de nieuwste functies
